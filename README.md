# TP1 — Introduction à la recherche reproductible avec Python, Jupyter et GitHub

Ce dépôt contient le travail pratique **TP1** réalisé dans le cadre d'un module d'analyse scientifique et de recherche reproductible en biologie.

## Contenu du dépôt
- `Analyse_Biologie.ipynb` : notebook Jupyter comprenant des cellules Markdown et Python, des calculs de croissance cellulaire avec **NumPy** (`heures`, `cellules` et `croissance_moyenne`), ainsi qu'une visualisation graphique avec **Matplotlib**.

## Objectifs du TP
- Utiliser Python et un notebook Jupyter pour structurer une analyse scientifique.
- Manipuler des données biologiques simples avec `NumPy`.
- Tracer un graphique d'évolution cellulaire avec `Matplotlib`.
- Publier et versionner le travail sur **GitHub**.
